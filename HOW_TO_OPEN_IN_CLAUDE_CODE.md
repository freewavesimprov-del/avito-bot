# Как открыть проект в Claude Code

## Шаг 1. Перенести папку к себе

Скопируйте всю папку `avito_bot_project/` в удобное место на вашем компьютере:

```bash
# Например, в домашнюю папку
cp -r /путь/к/avito_bot_project ~/projects/avito-bot
cd ~/projects/avito-bot
```

Рекомендую сразу инициализировать git:

```bash
git init
git add .
git commit -m "Initial: spec, prompt, data"
```

## Шаг 2. Открыть в Claude Code

Установите Claude Code если ещё не стоит (`npm install -g @anthropic-ai/claude-code`).

В терминале из папки проекта:

```bash
claude
```

Claude Code увидит `CLAUDE.md` и прочитает контекст проекта автоматически.

## Шаг 3. Первые команды для агента

Начните с чего-то из этого (скопируйте в Claude Code):

### Вариант A — сразу поручить первые задачи

> Прочитай `CLAUDE.md`, `SPEC.md` и `BACKLOG.md`. Возьми задачи T-001..T-005 из первого этапа и реализуй их. Запусти тесты, убедись что `GET /health` работает.

### Вариант B — сначала обсудить архитектуру

> Прочитай `CLAUDE.md` и `SPEC.md`. Есть ли в них пробелы или противоречия, которые стоит закрыть перед началом разработки? Верни список вопросов.

### Вариант C — сделать весь MVP сразу

> Реализуй Этапы 1-4 из `BACKLOG.md` (T-001..T-018). По каждой задаче: сначала план изменений, потом код, потом тесты. После каждой завершённой задачи делай git commit. Если понадобятся секреты (API-ключи) — просто используй плейсхолдеры в `.env.example`, не спрашивай у меня.

## Шаг 4. Что понадобится дальше от вас

Когда агент дойдёт до задач, требующих живых данных:

- **T-007** — создать приложение в Битриксе и получить `ACCESS_TOKEN`. Инструкцию Claude Code напишет сам в процессе.
- **T-010** — получить API-ключ Yandex Cloud (Yandex Cloud → IAM → создать API-ключ, + записать `folder_id`).
- **T-009** — тестовый прогон на вашей реальной открытой линии Битрикса.
- **T-025** — деплой на ваш VPS (можно передать SSH-ключ Claude Code либо деплоить руками по инструкции).

## Что уже подготовлено

- `CLAUDE.md` — весь контекст проекта и бизнеса
- `SPEC.md` — полное техническое ТЗ с примерами
- `BACKLOG.md` — 28 конкретных задач с приоритетом
- `README.md` — инструкция запуска/деплоя
- `app/prompts/system_prompt.md` — готовый system prompt с правилами и примерами диалогов
- `app/data/pilot_skus.json` — актуальные 18 SKU (цены и остатки на 22.04.2026)
- `app/data/faq_extras.md` — контекст про доставку/гарантию/подъём/сборку
- `requirements.txt` — стек пакетов
- `.env.example` — шаблон конфига
- `.gitignore` — для секретов и временных файлов

## Совет

После первого запуска попросите Claude Code создать в корне `CHANGELOG.md` и вести его — удобно когда вернётесь через неделю и хотите понять, что менялось.
